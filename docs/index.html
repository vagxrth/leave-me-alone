One identity network runs across thousands of Indian shops. Give your number to any of them once, and the rest can recognise you on sight — then message you about what you looked at.

First, see what a shop already has

Open any Indian shopping site, then run this on it. It reads that page's own storage, shows you the result, and sends nothing anywhere.

Reading what comes back

phone
The number that shop holds for you right now.
networkId
Your id across the whole network. Run it on a second, unrelated shop — it's the same value.
networkVisits
How many shops in the network have seen you. This is the number that tends to land.
thisShop
Visits to this shop. A 1 beside a phone number means it identified you on your first ever visit.

Then block it

Five rules. They stop the identity sync, the fingerprinting and the event collectors, and they leave cart and payment alone so you can still buy things.

Add to uBlock Origin or AdGuard

If nothing happens, add it by hand: uBlock Origin → Dashboard → Filter lists → Import, and paste this.

Pi-hole, AdGuard Home, NextDNS

https://vagxrth.github.io/leave-me-alone/gokwik-domains.txt

The stronger move costs nothing. Shop in Firefox, Brave or Safari. All three keep third-party frames from sharing storage between sites, which breaks the mechanism itself rather than one hostname at a time — and covers networks this list doesn't know about yet. Chrome doesn't do this.

Then ask for it to be deleted

Blocking stops new collection. It doesn't remove what's already held — that takes a written request, and under India's DPDP framework you're entitled to make one.

There's a template in the repository: erasure-letter.md. Run the scanner first so you can quote your own network id in it. A request naming the identifier is much harder to answer with a form reply than one that doesn't.

What this won't do

  • It won't undo what's already out there. If your number is already in the network, shops that have it can still message you. Blocking stops the next shop learning it.
  • It won't cover every vendor. This list covers one network — the largest. Others run on the same shops.
  • It isn't a privacy suite. Analytics, session recording and ad pixels are untouched. Use it alongside a general privacy list, not instead of one.

This page makes no external requests, sets no cookies and carries no analytics. The typeface is served from this site, not from Google. The scanner runs entirely in your browser and transmits nothing — read the source.
